# Version distribution plans by service day

การเปลี่ยนองค์ประกอบชุดสิ่งของจะสร้างแผนการแจก version ใหม่ซึ่งมีผลในวันให้บริการถัดไป ขณะที่การเติมและปรับยอดสต็อกมีผลทันที วิธีนี้ป้องกันไม่ให้ความหมายของ “รับครบชุด” เปลี่ยนระหว่างวันหรือระหว่างการจ่ายที่ต้อง retry และทำให้ประวัติอ้างอิงกติกาที่ใช้จริงได้
