# Protect citizen identifiers with encryption and keyed lookup

เลขประจำตัวประชาชนจะถูกเข้ารหัสก่อนจัดเก็บและมี keyed hash แยกสำหรับตรวจความซ้ำและค้นหาแบบ exact match หน้าจอจะแสดงเลขแบบปิดบังเป็นค่าเริ่มต้น วิธีนี้รักษาความสามารถในการส่งเลขให้เครื่องในอนาคตโดยลดการเปิดเผยข้อมูลหากฐานข้อมูลรั่ว แม้เพิ่มภาระการจัดการ encryption key และ key rotation
