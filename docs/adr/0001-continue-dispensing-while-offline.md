# Continue dispensing while offline

เครื่องแจกสิ่งของจะใช้รายชื่อผู้มีสิทธิ์ที่ซิงก์ล่าสุดและทำงานต่อเมื่อขาดการเชื่อมต่อ แล้วจึงส่งประวัติกลับมา reconcile เมื่อออนไลน์อีกครั้ง เราเลือกความต่อเนื่องของการช่วยเหลือเหนือการบังคับสิทธิ์หนึ่งครั้งต่อวันแบบสมบูรณ์ เพราะการหยุดแจกในพื้นที่อินเทอร์เน็ตล่มสร้างผลกระทบมากกว่า แม้ต้องยอมรับว่าผู้รับบางรายอาจรับซ้ำข้ามเครื่องระหว่าง offline ได้
