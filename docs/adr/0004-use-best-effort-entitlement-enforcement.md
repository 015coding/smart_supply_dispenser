# Use best-effort entitlement enforcement

ระบบจะไม่จองสิทธิ์ก่อนเริ่มแจกและจะตัดสิทธิ์รายวันหลังเครื่องยืนยันว่าจ่ายครบชุดเท่านั้น การจ่ายบางส่วนไม่ตัดสิทธิ์และผู้รับสามารถไปรับชุดเต็มจากเครื่องอื่นได้ เราเลือก workflow ที่เรียบง่ายและไม่ขัดขวางผู้ที่ได้ของไม่ครบ โดยยอมรับความเสี่ยงของซ้ำจากการจ่ายบางส่วนหรือการใช้สองเครื่องพร้อมกัน
